GESTURE CONTROLLER
==================
Requires Node 18+ (https://nodejs.org).

Run:
  Windows : double-click start.bat
  Mac     : double-click start.command  (first time: chmod +x start.command)
  Any OS  : node gesture.js

The browser opens automatically once ready (keep the black window open). If not, open the URL it prints.
First run needs internet (downloads ~15 MB into ./vendor). After that it works offline.

Controls: move index finger = cursor, pinch thumb+index = click. Mouse works as fallback.
